IT Help Center

Try these safe first steps before asking the lab teacher.

🌐

Internet not working

  • Check the Wi-Fi connection.
  • Check whether other websites open.
  • Ask the lab teacher to check the network.
⌨️

Keyboard or mouse issue

  • Check the USB connection.
  • Try another port only if permitted.
  • Ask before disconnecting shared equipment.
🐢

Computer running slowly

  • Save your work first.
  • Close apps you are not using.
  • Ask the teacher before restarting.

About This Project

Prepared for Skill Competition-cum-Exhibition 2026.

Project title: Smart School Helpdesk 2026

Trade: Information Technology

School: D CM SOE Chatra

Problem: Students may have to look in different places for school information and basic IT help.

Proposed solution: A simple website concept that groups student information, troubleshooting tips, and a sample help request feature.

Technology used: HTML structures the page, CSS styles the interface, and JavaScript makes the form interactive.

Student has a problem→Submit request→Ticket shown

Future Improvements

  • Teacher/admin login and verified notices.
  • Secure online database and teacher notifications.
  • Hindi and English language options.
  • Mobile-friendly access for students.
Honest project note: This is a working local prototype. It does not send requests to teachers or a school server. The demo request list is stored in the browser on this device.
